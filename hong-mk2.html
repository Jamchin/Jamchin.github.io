02 / Software

Control pipeline

UI input
to motor command.

GitHub ↗

Hover over a stage to see how a command travels from the computer to the arm. Keyboard users can focus a stage.

ComputerMATLAB UI

MATLAB runs locally on my computer. Each slider or button change fires a callback that updates a struct containing all target angles. That data is encoded as JSON text and sent to the Arduino.

ArduinoMessage buffer

The Arduino receives the data into a buffer and reads it one character at a time. This lets other functions keep running while the incoming message is being decoded.

HONG MK2Motor targets

The Arduino sends the target position to each motor. The motors then move the arm to their assigned positions.
